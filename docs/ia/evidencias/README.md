# Evidências visuais

As imagens desta pasta foram capturadas no frontend local, com uma conta fictícia e API simulada. As orientações exibidas foram produzidas pelo motor TF-IDF implementado. Não são evidência de chamada Claude, aplicação de migration em produção ou sessão autenticada no site publicado.

Testes executados: abertura da tela, exemplo de pergunta, análise, fontes, recuperação de histórico após recarga, exclusão e largura de 390px sem overflow horizontal do documento. O menu móvel é rolável horizontalmente.

Os testes de backend e frontend passaram em 20/11/2026. Os 19 testes automatizados executados incluem 7 específicos da A.L.I.A; os demais cobrem regressões em avatar, notificações, publicações e regras/validações existentes.
